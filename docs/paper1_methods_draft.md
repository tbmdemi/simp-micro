## Methods

### Problem formulation

We address the inverse design of two-dimensional auxetic metamaterial unit cells: given a target
macroscopic property pair (ν₁₂, ν₂₁) — the off-axis Poisson ratios of the homogenized unit cell —
produce a binary-like density field ρ ∈ [0, 1]^{64×64} whose effective mechanical response matches
the target. Forward evaluation uses solid isotropic material with penalization (SIMP) topology
optimization followed by numerical homogenization: the effective stiffness tensor **Q** is computed
from unit-cell displacement fields under periodic boundary conditions, and the Poisson ratios are
extracted from the full compliance inversion **S = Q⁻¹** (ν₁₂ = S₁₂/S₂₂), which remains valid at
arbitrary lattice rotations, unlike the shortcut ν₁₂ = Q₁₂/Q₂₂.

### Dataset generation

Candidate geometries are generated by SIMP topology optimization over the design space
(`volfrac`, `penal`, `rmin`, `move`, `void_size_frac`, `rotation_deg`, and base-material Poisson
ratio ν₀ in later stages), using four seed topologies including three anisotropic families
(hourglass, hexagonal, reentrant bow-tie) that produce auxetic behavior. The pipeline proceeds in
three stages: (i) Latin hypercube screening to identify dominant parameters (ν₁₂ correlates most
strongly with `volfrac`, |r| ≈ 0.87–0.96); (ii) an adaptive multi-batch design of experiments that
narrowed the `volfrac` range from [0.45, 0.70] to [0.50, 0.58] over 8 batches (7,920 samples,
100% FE convergence) and reallocated sampling toward seeds with lower manufacturability; and
(iii) dataset construction, in which 50×50 density fields are resized to 64×64 by box-filter
downsampling and labeled with ν₁₂, ν₂₁, and the achieved volume fraction.

Labels were cleaned by removing samples with oscillatory (limit-cycle) convergence, discrete or
out-of-physical-range topologies (33.6% of the raw pool). The production dataset (v2) contains
57,216 training / 2,044 validation / 2,044 test samples, split 70/15/15 stratified by seed, with
train-only symmetry augmentation (90°/270° rotations swap ν₁₂ ↔ ν₂₁; 180° rotations and flips
preserve them; ×6 augmentation).

### Property surrogate (Phase 4)

A convolutional surrogate predicts (ν₁₂, ν₂₁, volfrac_achieved) from the 64×64 density field:
four Conv(3×3)+BatchNorm+ReLU+MaxPool blocks (32→64→128→256 channels), global average pooling,
concatenation of a seed one-hot vector, and two fully connected layers. On the v2 test set
(n = 2,044) the surrogate reaches R² = 0.974 (ν₁₂), 0.964 (ν₂₁), 0.983 (volfrac). During cVAE
training this network is used frozen as a property-consistency critic; it is never trusted for
final scoring (see Evaluation).

### Conditional VAE (Phase 5)

The cVAE maps the condition vector c = (ν₁₂, ν₂₁) to a density field. The encoder applies four
convolutional blocks that retain spatial feature maps (4×4 at the deepest level), flattens the
4,096-dim feature map, concatenates c, and maps to the 32-dim latent mean/variance via the
regression head. The decoder concatenates [z, c] and upsamples through four transposed-convolution
blocks back to 64×64 with a final sigmoid. The training objective combines reconstruction
(binary cross-entropy), a β-weighted KL term, a property-consistency term evaluated by the frozen
surrogate, and regularization terms for total variation (anti-checkerboard), binarization
(ρ(1−ρ) penalty), and periodicity (edge mismatch penalty that makes unit cells tile seamlessly).

**Differentiable physics.** To prevent the decoder from exploiting surrogate blind spots
("surrogate exploitation"), a real-physics loss is added during a second training stage:
MSE between the target condition and ν₁₂/ν₂₁ obtained from an actual finite-element
homogenization solve with analytic gradients (`RealPhysicsNu`), executed inside the training loop.
To keep FE cost tractable (~50–100 ms/sample), the loss is evaluated on a random subsample of the
batch (`--real-physics-subsample 8`) every `--real-physics-every` epochs, parallelized over
workers, with a cached mesh topology. A two-stage schedule is mandatory: from-scratch training
with the physics loss at epoch 1 fails (deeply negative FE R² for 60 epochs).

### KAN regression head

In this work the three linear heads of the cVAE — `fc_mu`, `fc_logvar`, and the decoder
bottleneck `fc` — are replaced by Kolmogorov-Arnold layers (`EfficientKANLinear`, grid size 5,
cubic B-splines). These layers parameterize each scalar function as a learnable combination of
B-spline basis functions on a fixed grid, replacing the fixed nonlinearity of a neuron with an
adaptable univariate function. All other components are unchanged, isolating the effect of the
regression head. (A continuous WIRE INR decoder — Gabor-wavelet implicit representation with
ω₀ = s₀ = 10, one 128-unit hidden layer — is implemented and resolution-agnostic but has not yet
been trained; it is not part of the results reported here.)

### Checkpoint selection protocol

A central methodological decision is the model-selection oracle. Because the KL weight β is
annealed, validation loss is not a safe selection criterion, and we show in Results that on KAN
architectures it is actively harmful. All checkpoints are therefore selected by periodic
evaluation of true-FE R² (`--select-by fe_r2 --fe-eval-every 10`); surrogate-based accuracy
(`property_accuracy`) is used only as a secondary diagnostic.

### Two-stage KAN fine-tuning recipe

1. **Base KAN:** train the cVAE with the KAN heads (selected by `fe_r2`), producing
   `cvae_kan_best.pt`.
2. **Real-physics fine-tune:** resume from the base checkpoint with
   `--lambda-real-physics 2.0 --real-physics-subsample 8 --real-physics-every 20 --lr 2e-4`
   for 60 epochs (round 1 reference: λ = 1.0, every 50, lr 3e-4, 50 epochs), producing
   `cvae_kan_realphysics_v2.pt`.

### Evaluation

- **`property_accuracy` (surrogate-based):** for every test condition, sample z ∼ N(0, I),
  decode, predict (ν₁₂, ν₂₁) with the frozen surrogate, and compute per-target R² and MAE against
  the condition vector; the macro R² is the mean of the two per-target values. Used for
  architecture comparisons in this paper.
- **Best-of-N with true FE:** N candidate structures per condition; the winner is selected by an
  actual FE solve over all N (oracle mode) or over a surrogate-prefiltered top-K (pragmatic mode,
  K = 10), following the Deep-DRAM protocol. Reported as oracle R²(FE) and single-shot hit rate.
- **Manufacturability:** three binary checks — connectivity, minimum feature size, and
  periodicity (`passes_all`); a hard periodic-enforcement post-process (`force_periodic`) is
  applied at inference and increases `passes_all` by more than 10× at negligible property cost.

### Implementation

PyTorch; KAN layers from a vendored `efficient-kan` implementation; FE solves use the in-house
SIMP/homogenization engine with analytic sensitivities; dataset and checkpoints are versioned
under `outputs/`. All reported R² figures were re-measured with the current evaluation pipeline
(`property_accuracy`, surrogate v2, same test set) — including historical baselines — to keep
comparisons reproducible.
